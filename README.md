# Learn Excel & Sheets with Phoebe

Six 45-minute sessions for analysts on spreadsheets as data work with silent failure modes: grain
and types, lookups as joins, text that looks like numbers, pivots that count rows instead of orders,
when to leave, and a formula-audit bench. By Phoebe Fu.

- Open `index.html` to start. Static site, no build step.
- Running case: Ferncastle, a constructed online kitchenware shop. Its order rows are derived,
  masked rows from the Brazilian E-Commerce Public Dataset by Olist (Kaggle, CC BY-NC-SA 4.0): new
  IDs, no review text, no zip codes. The derived data is shared under the same licence.
- The bench (`courses/06-the-formula-audit-bench.html`) runs a small formula engine
  (`assets/exs-live.js`) over `assets/exs-data.js` in the browser; `materials/exs_reference.py`
  reproduces every number in Python.
- Every function default quoted on a page was read on Microsoft Support or Google Docs Editors Help.
